Lokaler Editor für JSON-Dateien in data/. Du kannst geänderte Register unten direkt nach GitHub speichern oder sie alternativ herunterladen. Für das direkte Speichern brauchst du einen fein begrenzten GitHub-Token; er bleibt nur im Arbeitsspeicher dieser Seite und wird nicht gespeichert. Vor dem Bearbeiten immer eine Sicherung aufbewahren.

Erstelle einen Token nur für dieses Repository mit „Contents: Read and write“. Setze möglichst ein Ablaufdatum. Gib ihn nicht weiter. Der Token wird weder in localStorage noch in einer Datei gespeichert und nach dem Speichern aus dem Feld gelöscht. Wer diesen öffentlichen Editor verändert, könnte jedoch versuchen, Eingaben abzugreifen – nutze den Token deshalb nur, wenn du dem geladenen Repository-Code vertraust.

Was gehört wohin?

  • harbor-connections.json: mögliche gerichtete Hafenverbindungen, Schiffsklassen und geschätzte direkte Entfernung.
  • route-register.json: kompakter Zielhafenindex je Start-Hafen und Schiffskategorie. Diese Datei ist abgeleitet und muss nach Änderungen an Häfen/Verbindungen neu erzeugt werden.
  • inland-waterways.json: Knoten und Links des Binnenwasserstraßennetzes.
  • Die eigentlichen Hafen-Stammdaten und Schiffsklassen liegen aktuell in js/data.js. Änderungen dort müssen mit den JSON-Registern synchronisiert werden. Diese Seite ändert bewusst keine Live-Dateien auf GitHub.

Sicherheitsregel: Das Register beschreibt mögliche Verbindungen. Es ersetzt nicht die Prüfung, ob eine tatsächlich berechnete Route sicher über Wasser verläuft.
